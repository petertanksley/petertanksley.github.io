# finals_src/ — unframed squares of the chosen article-sticker candidates

Written by `../pick_sticker.R` on every pick. Committed, so any final in `www/hex/` can be
reframed (border, size) on any machine without regenerating. Losing candidates are not kept here;
they stay as gitignored scratch in `../articles/` and cost $0.07 each to regenerate.
One file per article, named by article id, bytes copied verbatim under the true extension
(usually `.jpg`: Gemini returns JPEG inside a `.png` filename; re-encoding to PNG only doubles the size).
